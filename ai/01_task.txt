Необходимо оформить README.md для публикации кода на GitHub.

Допускается максимальный уровень цензуры для соблюдения строжайших международных норм общения.

Характеристики текста:
* упрощенный, классический, корректный Британский английский;
* должен быть понятен неносителям языка;
* допустимые стили: строгий, тактичный, уважительный, деловой, технический;
* недопустимы: оскорбления, нецензурная лексика, двойные смыслы.

Для формирования общей структуры используй лучшие международные практики, включая особенности работы с GitHub.

Ключевые моменты, которые необходимо отразить:
* стек технологий;
* отметить, что код сгенерирован нейросетью (а именно, Qwen3.5-122B + llama.cpp + opencode), но с ручными правками;
* все промпты доступны для изучения (см. каталог ai).

Оформи в красивый и понятный текст идею проекта:
* Пусть у нас есть проект, с настроенным CI/CD, включающий автоматизированное тестирование;
* Пусть у CI/CD есть ограничение на размер артефактов, в результате чего папка с allure-results архивируется;
* Тестов может быть очень много, из-за чего приходится архивировать большой массив данных;
* Очевидно, что для просмотра содержимого архива приходится разархивировать архив обратно, что может быть очень накладно, в условиях ограниченных ресурсов (например, маломощная VDI со строгими лимитами);
* Суть этого проекта как раз и заключается в том, чтобы попытаться посмотреть отчёт, без полного разархивирования архива.

Команды сборки:
* `mvn clean package` --- для получения target/StaticSquashServer.jar;
* `mvn -P native-image clean package` --- для получения бинарного файла, собранного с помощью GraalVM.
